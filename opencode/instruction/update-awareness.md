# Update Awareness

When the user asks whether this setup is current, route them to `/check-updates` instead of guessing.

Trigger phrases include:

- "am I up to date?"
- "check for updates"
- "update my tools"
- "get the latest skills"
- "update OpenCode"
- "update Just Vibes"
- "are there new commands?"

Say: "I can check that with `/check-updates`." Then run or suggest that command.

Do not poll for updates proactively at startup.
